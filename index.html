OSHIVERSE

複数の推し(VTuber)を、ひとつのアプリで。

OshiVerseは、複数のVTuberを応援するファンのためのiPhone・iPadアプリです。 配信中の推しをマルチビューで4画面ずつ並べて見られ、 配信開始の通知や、新しい推しとの出会いもサポートします。

App Storeで公開準備中（iPhone・iPad）

主な機能

推しの登録と配信状況の一覧、マルチビュー視聴（YouTube・Twitch）、ライブチャットへのコメント、配信開始の通知（Pro）、VTuberランキング・記念配信・おすすめ配信、推しリストのバックアップと同期

使用しているAPI

YouTube API Services（YouTube Data API v3・埋め込みプレイヤー）を利用しています。本アプリを利用することで、YouTube利用規約に同意したものとみなされます。

開発者・お問い合わせ

個人開発者による開発です。お問い合わせは oshiverse-support@googlegroups.com までお願いします。
