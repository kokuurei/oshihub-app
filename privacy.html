プライバシーポリシー

最終更新日: 2026年10月5日 ・ English

OshiVerse（以下「本アプリ」）は、個人開発者が開発するiOS・iPadOSアプリです。本ポリシーは、本アプリがどのような情報を取得し、どのように利用・処理・共有・保存・削除するかを説明します。

1. YouTube API Servicesの利用について

本アプリはYouTube API Servicesを利用しています。本アプリを利用することにより、ユーザーはYouTube利用規約に拘束されることに同意したものとみなされます。あわせてGoogleプライバシーポリシーもご確認ください。

2. 取得する情報と利用目的

  • YouTube・Twitchの公開情報（チャンネル名・アイコン画像・登録者数・動画のタイトルや統計・配信状況など）: YouTube Data APIおよびTwitchの公開情報から取得し、アプリ内での表示のためにのみ利用します。
  • Googleアカウントでのログイン（任意）: 「YouTube連携」でGoogleにログインした場合にのみ、Googleアカウントの識別子とアクセストークンを取得します。アクセストークンはお使いの端末内にのみ保存し、開発者のサーバーへは送信しません。詳しくは「3. Googleユーザーデータの取り扱い」をご覧ください。
  • Twitchでのログイン（任意）: Twitchにログインした場合、フォロー中のチャンネルの取り込みと、サブスク限定配信の視聴のために、Twitchのアクセストークンを端末内に保存して利用します。ログイン時の認証コードの受け渡しだけ開発者のサーバーを中継しますが、サーバーにトークンは保存しません。
  • Appleでサインイン（任意）: 「バックアップと同期」でAppleでサインインした場合、Appleが発行するユーザー識別子のみを受け取ります。氏名・メールアドレスは要求しません。
  • 同期するデータ: ログインしている場合、推しリスト（登録したチャンネルの情報と、ユーザーが入力したメモ等）、マルチビューの並び順、外観や一覧の並べ方の設定を、iPhone・iPad間でそろえるためにサーバーへ保存します。
  • プッシュ通知用トークン（Appleが発行するデバイストークン、Firebase Cloud Messagingのトークン）、フォロー中のチャンネルIDの一覧と端末の言語設定: 配信開始の検知・通知の送信と、通知の言語を合わせるために利用します。
  • 購入に関する情報: 有料プラン（OshiVerse Pro）と応援プランの購入・決済はAppleが処理し、本アプリはカード番号などの決済情報を取得しません。購入の有効性の確認のため、Appleが発行する取引情報（取引ID・商品・購入日時）を利用します。応援プランでは、掲載のために取引情報・応援先のチャンネル・掲載期間をサーバーに保存し、任意で入力された応援者の名前をアプリ内の掲載やシェア文に表示します。
  • アプリの利用状況: 機能の改善のため、Firebase Analytics（Google）により、画面の表示や機能の利用回数などのアプリ内の操作と、アプリごとに発行される識別子を取得します。氏名などの個人を特定する情報とは結び付けず、広告には利用しません。
  • 不正利用の防止のための情報: サーバーへの通信が本アプリからのものであることを確かめるため、Firebase App Check（AppleのApp Attest）による端末の正当性の確認を行います。
  • PR枠の表示・タップ回数: 掲載の効果を集計するため、PRの表示・タップ・登録の回数を日別の件数として記録します（誰が見たかは記録しません）。

本アプリは、ユーザーの氏名・住所・位置情報・連絡先などを収集しません。

3. Googleユーザーデータの取り扱い

本アプリは、ユーザーが「YouTube連携」でGoogleにログインし、許可した場合に限り、YouTube Data APIの権限（https://www.googleapis.com/auth/youtube.force-ssl）を使って、次の操作だけを行います。

  • ユーザーが「取り込む」を選んだときに、YouTubeの登録チャンネルの一覧を読み込み、ユーザーが選んだチャンネルだけを推しリストに追加する
  • ユーザーがボタンを押したときに、チャンネル登録を行う
  • ユーザーがボタンを押したときに、動画に高評価を付ける、またはその状態を表示する

ライブチャットへのコメントと、メンバー限定配信の視聴は、上記の権限を使いません。本アプリ内に表示するYouTubeのページ（youtube.com）に、ユーザーがYouTube（Google）へログインして行います。ログイン情報はGoogle・YouTubeのページに直接入力され、本アプリは取得しません。コメントは本アプリを経由せずにYouTubeへ投稿され、本アプリはその内容を保存しません。

本アプリによるGoogle APIから受け取った情報の利用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）に準拠します。Googleユーザーデータは上記の機能の提供のためだけに利用し、広告に利用したり、第三者に販売・提供したりすることはありません。人がGoogleユーザーデータを閲覧することはありません（ユーザーの同意がある場合、セキュリティ上の必要がある場合、法令に従う場合を除きます）。登録チャンネルの一覧は端末内で処理し、ユーザーが推しとして追加したチャンネルだけが推しリストとして同期されます。

4. 情報の処理と共有（内部・外部での取り扱い）

  • 端末内での保存: 登録した推しリストやYouTube・Twitchから取得した表示用データ、ログイン情報は、お使いの端末内に保存されます。
  • 開発者のサーバーへの送信: 次の情報は、本アプリの機能提供のために開発者が管理するサーバー（Google Cloud / Firebase）へ送信・保存されます。①プッシュ通知の配信に必要なトークン・端末の言語設定とフォロー中のYouTubeチャンネルID一覧、②ログイン時の推しリスト・並び順・設定（同期用）、③推し追加時のチャンネル公開情報（アプリ内のVTuber名簿の充実のため。「誰がフォローしているか」は送信されません）、④応援プランの取引情報と任意の応援者名、⑤PR枠の日別の表示・タップ回数、⑥アプリの利用状況（Firebase Analytics）。
  • 第三者への提供: 上記のGoogle Cloud / Firebase（インフラ・分析の提供者）およびApple（決済・サインイン）による処理を除き、取得した情報を第三者に販売・共有・提供することはありません。広告目的での利用も行いません。

5. 端末内への情報の保存（Cookie等）

本アプリは、設定や推しリスト等の情報をお使いの端末内（アプリ領域）に保存します。また、本アプリ内のYouTube埋め込みプレイヤーおよびTwitch埋め込みプレイヤーの表示にあたり、YouTube（Google）およびTwitchが、Cookieまたは類似の技術を通じて端末上に情報を保存・アクセスすることがあります。これらの取り扱いはGoogleプライバシーポリシーおよびTwitchプライバシーノーティスに従います。

6. データの保持と削除

  • YouTube APIから取得したデータは、アプリ利用中に定期的に最新の情報へ更新・上書きされ、30日を超えて古いまま保持しません。
  • サーバー上の統計データ（登録者数の推移など）は30日を超えた分から順次削除されます。
  • 推しを削除すると、対応する端末内のデータは即座に削除されます。アプリを削除すると端末内の全データが削除されます。
  • アカウントの削除: アプリの「設定」→「アカウントを削除」から、いつでもサーバーに保存した推しリスト・並び順・設定とアカウントを削除できます。Appleでサインインしていた場合はAppleでのサインインの許可を、Googleでログインしていた場合は本アプリへのGoogleの許可を、あわせて取り消します。
  • アプリを使えない場合など、削除のご依頼は下記の連絡先でも受け付けます。

7. アクセス権の取り消し

本アプリに許可したGoogleのアクセス権は、Googleアカウントのセキュリティ設定ページからいつでも取り消すことができます。Appleでサインインの利用は、iPhoneの「設定」→ユーザー名→「Appleでサインイン」から停止できます。
