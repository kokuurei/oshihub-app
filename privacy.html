プライバシーポリシー

最終更新日: 2026年7月29日

OshiVerse（以下「本アプリ」）は、個人開発者が開発するiOSアプリです。本ポリシーは、本アプリがどのような情報を取得し、どのように利用・処理・共有するかを説明します。

1. YouTube API Servicesの利用について

本アプリはYouTube API Servicesを利用しています。本アプリを利用することにより、ユーザーはYouTube利用規約およびGoogleプライバシーポリシーに同意したものとみなされます。

2. 取得する情報と利用目的

  • YouTubeの公開情報（チャンネル名・アイコン画像・登録者数・動画のタイトルや統計・配信状況など）: YouTube Data APIを通じて取得し、アプリ内での表示のためにのみ利用します。
  • Googleアカウント情報（ユーザーID・アクセストークン）: ユーザーが任意でGoogleログインした場合にのみ取得します。ライブチャットへのコメント投稿と、推しリストのクラウド同期のために利用します。ログインしなくても本アプリの主要機能は利用できます。
  • プッシュ通知用トークン（Appleが発行するデバイストークン）: 配信開始通知の送信のために利用します。

本アプリは、ユーザーの氏名・住所・位置情報などを収集しません。

3. 情報の処理と共有（内部・外部での取り扱い）

  • 端末内での保存: 登録した推しリストやYouTubeから取得した表示用データは、お使いの端末内に保存されます。
  • 開発者のサーバーへの送信: 次の情報は、本アプリの機能提供のために開発者が管理するサーバー（Google Cloud / Firebase）へ送信・保存されます。①プッシュ通知の配信に必要なデバイストークンとフォロー中のYouTubeチャンネルID一覧、②Googleログイン利用時の推しリスト（クラウド同期用）、③推し追加時のチャンネル公開情報（アプリ内のVTuber名簿の充実のため。「誰がフォローしているか」は送信されません）。
  • 第三者への提供: 上記のGoogle Cloud / Firebase（インフラ提供者）による処理を除き、取得した情報を第三者に販売・共有・提供することはありません。広告目的での利用も行いません。

4. 端末内への情報の保存（Cookie等）

本アプリは、設定や推しリスト等の情報をお使いの端末内（アプリ領域）に保存します。また、本アプリ内のYouTube埋め込みプレイヤーおよびTwitch埋め込みプレイヤーの表示にあたり、YouTube（Google）およびTwitchが、Cookieまたは類似の技術を通じて端末上に情報を保存・アクセスすることがあります。これらの取り扱いはGoogleプライバシーポリシーおよびTwitchプライバシーノーティスに従います。

5. データの保持と削除

  • YouTube APIから取得したデータは、アプリ利用中に定期的（数分間隔）に最新の情報へ更新・上書きされます。
  • サーバー上の統計データ（登録者数の推移など）は30日を超えた分から順次削除されます。
  • 推しを削除すると、対応する端末内のデータは即座に削除されます。アプリを削除すると端末内の全データが削除されます。
  • サーバーに保存された同期データ等の削除をご希望の場合は、下記の連絡先までご連絡ください。

6. アクセス権の取り消し

Googleログインで本アプリに許可したアクセス権は、Googleアカウントのセキュリティ設定ページからいつでも取り消すことができます。
